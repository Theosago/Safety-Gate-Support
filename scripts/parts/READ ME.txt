ADD THE 19 SUPPLIED SAFE2CROSS PARTS — NO APP UPGRADE

1. Extract this download into a folder on the Windows PC where you use Safety Gate Support.
2. Close Safety Gate Support (and other copies using the same shared data).
3. Double-click Add parts.cmd. It reads the app's saved shared-folder setting.
4. After the success message, reopen your existing app and select Parts.

The updater adds missing stock numbers, leaves existing records and extra fields intact,
and saves an exact backup under the shared folder's Data\Backups directory.
Quantities are the supplied stock snapshot, not live inventory. Stock 0117719 had no site supplied.

The data is included in this download; nothing is fetched or installed at runtime.
The script only changes Data\parts.json, creates its backup, and uses the app's shared write lock.
It does not replace the executable, move asset files, change settings, or program hardware.

If the drive is unavailable or you lack write access, the update stops with an error.
If the app's shared-folder setting is missing, configure it in the existing app first.
An explicit path is also supported from PowerShell:
  .\Add-Safe2CrossParts.ps1 -SharedRoot 'Q:\SafetyGateSupport'
Use your actual shared folder if it differs from that example.
